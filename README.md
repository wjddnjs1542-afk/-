# TripFlow AI v0.8 — AI 현장 여행 도우미

## 핵심 기능
- 현재 시간, 위치, 날씨, 오늘 일정, 장소 영업상태를 종합한 `AI 지금 뭐하지?` 추천
- Open-Meteo 기반 현재 날씨·체감온도·강수확률 표시
- Google Places로 추가한 장소의 영업 중/종료, 평점 표시
- 추천 장소를 지도에서 바로 확인하고 Google Maps 길찾기로 연결
- 모바일 하단 플로팅 버튼과 50:50 바텀시트 유지
- 작은 화면에서도 일정 영역을 독립적으로 스크롤

## 사용 순서
1. GitHub Pages에 배포합니다.
2. 위치 권한을 허용하고 `내 위치`를 누릅니다.
3. `AI 지금 뭐하지?`를 누르면 현재 상황에 맞는 다음 행동을 추천합니다.
4. `다음 장소 길찾기`로 Google Maps 안내를 시작합니다.

## 참고
- 별도의 AI API를 호출하지 않고, 현장 데이터를 조합하는 규칙 기반 추천 엔진입니다.
- 날씨는 Open-Meteo, 장소·영업시간·평점과 지도는 Google Maps/Places API를 사용합니다.
- 영업시간은 Google Places 검색으로 추가되어 placeId가 저장된 장소부터 확인됩니다. 기존 기본 일정은 장소를 다시 검색해 교체하면 영업정보가 연결됩니다.
- API 키 보호 설정은 후속 버전에서 진행할 수 있습니다.
