# TripFlow AI v0.8.5

실제 Google 도로 경로만 표시하도록 길찾기 로직을 수정한 버전입니다.

## 핵심 수정
- 도보 선택 시 도보 경로만 요청
- 대중교통 선택 시 대중교통 경로만 요청
- 자동차 선택 시 자동차 경로만 요청
- 다른 교통수단으로 자동 대체하는 동작 제거
- API 실패 시 직선 임시 경로 표시 제거
- 실제 Directions 응답이 있을 때만 도로·골목을 따라 경로선 표시
- 이동수단 변경 시 기존 경로를 지우고 새 경로 재계산
- 모바일 내부 길찾기 패널 개선
- 오류 코드와 Google Cloud 설정 필요 여부를 화면에 표시

## 반드시 필요한 Google Cloud API
- Maps JavaScript API
- Directions API (Legacy)

두 API가 모두 활성화되어 있어야 TripFlow 내부 지도에 실제 경로가 표시됩니다.

## 배포
기존 파일을 모두 교체하여 업로드하면 됩니다.
별도의 `?v=085` 주소를 붙이지 않아도 새 파일명을 사용하도록 구성했습니다.
