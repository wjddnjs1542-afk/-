# TripFlow AI v0.8.2

모바일 여행 현장에서 현재 위치를 기준으로 날씨와 주변 장소를 추천하는 버전입니다.

## 주요 기능
- 우측 상단 `지금 뭐하지?` 버튼만 유지
- 브라우저의 실시간 GPS 위치를 기준으로 현장 날씨 조회
- 현재 위치·시간대·날씨·영업 여부를 종합해 반경 약 2.5km의 음식점, 카페, 관광지, 공원 또는 실내 장소 추천
- 비가 올 가능성이 높으면 박물관 등 실내 장소 우선 추천
- 각 추천 장소의 거리, 영업 여부, 평점과 리뷰 수 표시
- 추천 장소별 Google Maps 길찾기 연결
- 위치 권한이 없을 경우 임의의 도시 좌표를 사용하지 않고 권한 필요 안내
- 기존 일정, 장소검색, 지도·일정 50:50 모바일 바텀시트 기능 유지

## 사용 전 확인
- HTTPS로 배포된 GitHub Pages에서 실행해 주세요.
- iPhone 설정에서 Safari 또는 사용 중인 브라우저의 위치 접근을 허용해야 합니다.
- Google Maps JavaScript API, Places API, Directions API가 활성화되어 있어야 합니다.
