# TripFlow AI v0.4 — 시간 기반 플래닝

## 추가 기능
- 가는 편·오는 편 항공사, 편명, 항공기종, 출도착 공항 및 일시 입력
- 항공편을 여행 전체 시작·종료시간의 기준으로 표시
- 장소 추가 시 희망 도착시간과 체류시간 입력
- 기존 장소의 시간·체류시간 수정
- 시간 고정 장소를 우선 보존하는 스마트 동선
- 거리와 예상 이동시간을 이용한 시간 충돌·지각 가능성 경고
- 실제 경로에 진행 방향 화살표 표시
- 자동차·대중교통·도보 유지

## 중요
현재 “스마트 동선”은 브라우저 안에서 작동하는 시간·거리 기반 휴리스틱입니다.
외부 생성형 AI 서버를 호출하는 기능은 아직 포함하지 않았습니다.
다음 단계에서 AI API와 연결하면 식사시간, 영업시간, 아동 동반, 선호도까지 반영할 수 있습니다.
