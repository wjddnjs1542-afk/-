# TripFlow AI v0.8.4

추천 장소 길찾기를 실제 모바일 현장용 인터페이스로 개선한 버전입니다.

## 주요 변경
- 추천 장소 길찾기 선택 시 TripFlow 지도 내부에 전용 경로 패널 표시
- 지도 위에서 도보 / 대중교통 / 자동차 즉시 선택
- 이동수단 변경 시 같은 목적지로 경로, 거리, 예상시간 재계산
- 현재 선택된 이동수단과 경로 상태 표시
- 상세 이동안내 버튼 제공
- 모바일에서 길찾기 시작 시 일정 패널을 내려 지도 영역 확보
- 경로 닫기 기능 추가
- Directions API 실패 시 직선 거리와 예상시간을 임시 안내로 명확히 구분
- 캐시 갱신을 위해 app.v084.js, styles.v084.css 사용

## 업로드
ZIP 압축을 풀고 저장소의 기존 파일을 모두 교체해 업로드하세요.
배포 후 주소 끝에 `?v=084`를 한 번 붙여 접속하면 이전 모바일 캐시를 우회할 수 있습니다.
