# TripFlow AI · Phase 1.2

## 추가 기능
- 내 현위치 버튼과 정확도 범위 표시
- 하단 지도 상태 문구 제거
- 장소 번호와 동일한 순서의 선홍색 경로 표시
- 자동차 / 대중교통 / 도보 / 자전거 선택
- 각 구간의 거리, 시간, 이동방법 안내

## 업로드
압축을 풀고 `index.html`, `styles.css`, `app.js`를 GitHub 저장소의 기존 파일과 교체합니다.

## 유의사항
- 현위치는 HTTPS 환경과 브라우저 위치 권한이 필요합니다.
- 대중교통은 여러 경유지를 한 번에 지원하지 않아 장소 사이를 구간별로 계산합니다.
- 자전거 경로는 지역에 따라 제공되지 않을 수 있습니다.
- 도보·자전거 경로는 현지 표지와 안전 상황을 확인하세요.
